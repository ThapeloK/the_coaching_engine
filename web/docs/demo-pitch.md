# Demo 讲稿 — Mary-Susan（2026-09-04）

## 开场钩子（30 秒）

康奈尔酒店管理学院这学期也在做 AI 培训（Info 5940 × Statler Hotel 项目）：
他们建了模拟客人 + 实时教练 + 报告，但文章里没有一条效果数据 ——
因为练习只能证明「会做」，证明不了「现场会做」。
我们补上的就是这一个闭环：现场观察 + 差距可视化 + 人工验证 + 校准指标。

## Demo 路径（5 分钟）

1. `/` 落地页 — 讲双流概念：两个独立数据流，AI 合流成带引用的建议，
   无人工裁决不路由。
2. `/staff` — debrief 框输入一段班次经历（可现场打字或直接讲 Diego 的
   「starter missing」故事）→ 酒店标准条款回来（「先道歉后补偿」）→
   点进去生成个性化场景。
3. `/staff/practice/5e9d-personal` — 练习对话：说一句敷衍的回复（打字或按
   麦克风语音输入，识别结果填入输入框确认后发出），让客人情绪升级 →
   分隔线出现「getting more upset」。
4. `/manager/observe` — 选 Diego，20 秒记一次现场观察（3 个评分）→
   自动跳到 gap 页。
5. `/manager/gap` — 散点图：Recovery 4.0 练习 vs 2.0 现场 = BLOCKED
   （「练得好、现场做不出 → 不是培训问题，是授权问题」）。
6. `/manager/verify/r91a-diego` — 展开每条引用（练习原话 / 经理观察 /
   SOP 条款）→ Confirm → 校准数字 0.840 → 0.846 动起来
   （「这就是系统在学习」）。

## 每屏一句话

| 屏幕 | 讲什么 |
|---|---|
| landing | 双流 + 人工验证是核心 |
| debrief | 员工视角：隐私、非惩罚、用员工自己的话生成练习 |
| practice | 情绪状态机是模拟质量 |
| observe | 经理 20 秒，AI 读完 |
| gap | 散点 = 差距可见；BLOCKED 判断 |
| verify | 每条引用可点开核对；裁决训练校准 |

## 评审可能问

- **「这和 Cornell 有什么区别？」** → 他们停在练习；我们有现场流 +
  验证闭环 + 校准指标。
- **「AI 会不会直接惩罚员工？」** → 不会：无人工裁决不路由；团队洞察
  k-匿名；员工可见所有关于自己的记录。
- **「数据从哪来？」** → 现在是 mock；SOP 引用与 API 契约已就位，
  接入真实 AI/RAG 即填充。
- **「校准数字怎么算？」** → 每次裁决后更新的 agreement rate（演示中为
  模拟数据）；真实系统里是 AI 判断与经理判断的一致性。
